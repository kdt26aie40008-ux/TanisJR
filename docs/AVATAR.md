# オリジナル3Dアバターの作り方

第二の自分AIは VRM 形式（VRM 1.0 / 0.x）のアバターを表示できます。
アバターは「3Dアバター」画面から読み込み、選択・名前変更・削除ができます。

## 1. 仮モデルと正式なモデル

- 動作確認用のモデル（例: VRM コンソーシアムのサンプル「Seed-san」）は **仮モデル** として登録してください。画面に常に「仮モデル」と表示されます。
- 自分用のオリジナルモデルができたら読み込み、「正式なモデルにする」を押します。

## 2. VRoid Studio で作る（無料・推奨）

1. [VRoid Studio](https://vroid.com/studio) をインストールして起動し、新規モデルを作成します。
2. 顔・髪型・衣装を編集します。
3. 「撮影・エクスポート」→「エクスポート」→ **VRM 1.0** を選びます。
4. ライセンス情報（メタ情報）を入力します。
   - アバターの利用許可、商用利用、クレジット表記、再配布、改変 などを設定します。
   - 自分専用なら「作者のみ」で構いません。
5. 出力した `.vrm` ファイルを、このアプリの「3Dアバター」画面から読み込みます。

## 3. 表情・口パクが動く条件

アプリは VRM の標準表情を使います。VRoid Studio で作ったモデルは最初から対応しています。

| 用途 | 使用する表情 |
|---|---|
| まばたき | `blink` |
| 口パク | `aa` |
| 感情 | `happy` / `sad` / `surprised` / `relaxed` / `angry` |

これらが無いモデルでも表示はできますが、その動きだけが行われません。

## 4. 他人が作ったモデルを使う場合

- 配布元の利用規約、および VRM 内のライセンス情報（「3Dアバター」画面の「ライセンス情報」で確認できます）を必ず守ってください。
- クレジット表記が必要なモデルは、表示中に作者名が画面に表示されます。
- 再配布不可のモデルは、他人に渡したりリポジトリに含めたりしないでください（`*.vrm` は Git の管理対象外です）。

## 5. 保存場所

- 読み込んだモデルは `data/avatars/<ID>.vrm` に保存されます（ファイル名はアプリが決めます）。
- バックアップ（`.twinbak`）にはアバターのファイルは含まれません。PC を移行した場合は読み込み直してください。
