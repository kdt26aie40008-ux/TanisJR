# Google カレンダー連携の準備（管理者向け・1回だけ）

アプリに Google の登録ファイル（OAuth クライアント）を1つ置いておくと、使う人は「予定」画面で
**「Google でログインして連携」を押してログインするだけ** で、自分の Google カレンダーと連携できます。
使う人が Google Cloud を操作したり、JSON ファイルを選んだりする必要はありません。

この準備は、チームの誰か1人（管理者）が1回だけ行います。

## 1. Google Cloud で登録する（約10分・無料）

1. [Google Cloud コンソール](https://console.cloud.google.com/projectcreate) で新しいプロジェクトを作成します（例: `twin-ai`）。
2. 「API とサービス › ライブラリ」で **Google Calendar API** を検索し、「有効にする」を押します。
3. 「API とサービス › OAuth 同意画面」（「Google Auth Platform」）で次のように設定します。
   - ユーザーの種類: **外部**
   - アプリ名: 例「第二の自分AI」、ユーザーサポートメール・デベロッパーの連絡先: 管理者のメールアドレス
   - データアクセス（スコープ）: `https://www.googleapis.com/auth/calendar.events` を追加
4. 「対象」（公開ステータス）を決めます。

   | 公開ステータス | 使える人 | 注意 |
   |---|---|---|
   | テスト | 「テストユーザー」に登録した Google アカウントだけ（100人まで） | ログインは **7日ごとにやり直し** が必要 |
   | 本番環境（確認前） | 誰でも（100人まで） | ログイン時に「このアプリは Google で確認されていません」と表示される（「詳細」→「移動」で進める）。ログインのやり直しは不要 |
   | 本番環境（確認済み） | 誰でも | Google の審査が必要（プライバシーポリシーのページなど）。警告は出ない |

   チームで使うだけなら「本番環境（確認前）」が手軽です。

5. 「認証情報 › 認証情報を作成 › OAuth クライアント ID」で、アプリケーションの種類 **「デスクトップアプリ」** を選んで作成し、
   **JSON をダウンロード** します。

## 2. アプリに置く

ダウンロードした JSON ファイルの名前を `google-oauth-client.json` に変えて、プロジェクトの `config` フォルダーに置きます。

```
TanisJr/
  config/
    google-oauth-client.json   ← ここ
```

アプリを起動し直すと、「予定」画面に「Google でログインして連携」ボタンが表示されます。
別の場所に置く場合は、環境変数 `TWIN_GOOGLE_CLIENT` にファイルの場所を指定します。

## 3. チームで共有する方法

このファイルは `.gitignore` で Git の管理対象外にしてあります（初期設定）。共有方法を次のどちらかから選んでください。

- **チーム内で配る（おすすめ）**: 管理者がファイルをチームのメンバーに直接渡し、各自が `config` フォルダーに置きます。
- **リポジトリーに入れる**: `.gitignore` の `config/google-oauth-client.json` の行を消してコミットします。
  デスクトップアプリ用のクライアント情報は Google の説明でも「秘密として扱えない」ものとされていますが、
  公開リポジトリーに載せると、他の人が同じ登録を使ってログイン画面を出せるようになります（あなたのカレンダーが見られるわけではありません。
  利用者数の上限（100人）を消費される可能性があります）。

## 安全について

- 要求する権限は「予定の表示と編集（calendar.events）」だけです。
- ログイン後のトークンは、使う人の PC に暗号化して保存されます（管理者や他のメンバーには共有されません）。
- 予定の追加・変更・削除は、アプリで「承認して実行」を押したときだけ行われます。
- 使う人がこの PC で自分の登録ファイルを登録した場合は、そちらが優先されます。
